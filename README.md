About the Project

This project is a simple flood reporting system designed using Flowgorithm. It allows users to enter a flood location, describe the situation, and select the danger level.
Objectives
The aim is to make flood reporting easier and help identify areas affected by flooding.
Tools Used
Flowgorithm: Used to design and test the program.
 GitHub: Used to store the project and track changes.
How It Works
The user enters the flood location, describes the flooding, and selects High, Medium, or Low as the danger level. The program then displays a message based on the selected level and confirms that the report has been recorded successfully.
Testing
The program was tested with all three danger levels to check that it displays the correct messages.
Conclusion
This project shows how a simple computer program can help organize flood reports and make flood risk information easier to understand.
